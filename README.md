Entry for the [make.fun bounty "The joke the reviewer laughs at"](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329): a program (`main.py`, Python 3.13) that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`.

The joke:

> I told my agent that 'LGTM' is my job. It approved its own PR, merged it, and now I'm reviewing code that already shipped.

An AI judge compares entries two at a time; the 20 best win rates share $35, paid in USDC on Solana.
